# Unpacker-and-Repacker-to-MK-Shaolin-Monks---source-code
Source code for the Unpacker and Repacker of the GAMEDATA.WAD container, which contains a lot of assets and graphics resources. DecoAlso with the PS2 game version. The EWDF Decoder-Encoder contains the source for the compression used by the game files. The EWDF tool is able to decompress and recompress the EWDF files.
